# HxCPP Setup

Dependencies:
- **Haxe**: [install from here](https://haxe.org/download/) (version `4.3.4`).
- **HaxeLib**: [install from here](https://lib.haxe.org/documentation/using-haxelib/#install) (version `4.3.4`).
- **HxCPP** [install from here](https://github.com/HaxeFoundation/hxcpp).
- Ensure the `haxelib` and `haxe` binaries are accessible from your `$PATH`.
