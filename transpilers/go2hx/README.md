# Go2Hx Setup

Dependencies:
- **Go**: [install from here](https://go.dev/doc/install) (version `1.20+`).
- **Haxe**: [install from here](https://haxe.org/download/) (version `4.3.4`).
- **HaxeLib**: [install from here](https://lib.haxe.org/documentation/using-haxelib/#install) (version `4.3.4`).
- **Go2Hx**: [install from here](https://github.com/go2hx/go2hx).
- Ensure the `go`, `haxelib`, and `haxe` binaries are accessible from your `$PATH`.
